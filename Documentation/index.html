HTML Headings

HTML stands for HyperText Markup Language. It is the standard language used to create and structure content on the web. HTML uses elements and tags to define headings, paragraphs, links, images, and other content.

HTML is easy to learn and forms the foundation of web development. Every website uses HTML, and learning it helps you understand how web pages are structured and displayed in browsers.

An HTML document consists of a document type declaration, the html element, the head element, and the body element. The head contains metadata, while the body contains the visible content of the page.

HTML headings are defined with the <h1> to <h6> tags.

<h1> defines the most important heading. <h6> defines the least important heading. 


<h1>This is heading 1</h1>
<h2>This is heading 2</h2>
<h3>This is heading 3</h3>
<h4>This is heading 4</h4>
<h5>This is heading 5</h5>
<h6>This is heading 6</h6>
  1. HTML is used to create the structure of web pages
  2. HTML elements are defined using tags
  3. Attributes provide extra information about elements
  4. HTML supports links, images, tables, and forms
  5. HTML works together with CSS and JavaScript
HTML Links

HTML elements are defined by a start tag, content, and an end tag. Some elements can be nested inside others, allowing complex layouts to be created using simple building blocks.

HTML attributes provide additional information about elements. They are written inside the start tag and usually come in name and value pairs such as class, id, href, and src.

Semantic HTML elements clearly describe their meaning in a human-readable way. Elements like header, footer, section, and article improve accessibility and make the code easier to understand.

HTML links are defined with the <a> tag.

The href attribute specifies the destination URL of the link. 


<a href="https://www.google.com">Visit Google</a>

Links can also open in a new tab using the target="_blank" attribute. 


<a href="https://www.google.com" target="_blank">
  Visit Google
</a>
